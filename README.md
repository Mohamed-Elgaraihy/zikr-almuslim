# ذكر المسلم

تطبيق أذكار يعمل على أندرويد وآيفون والويب وويندوز وماك ولينكس. الواجهة عربية من اليمين لليسار، وعلى نمط ورد [أذكار المساء في إسلام بوك](https://www.islambook.com/azkar/2/%D8%A3%D8%B0%D9%83%D8%A7%D8%B1-%D8%A7%D9%84%D9%85%D8%B3%D8%A7%D8%A1): نص الذكر في وسط البطاقة، وتحته شريط أخضر يعدّ تنازليًا حتى الاكتمال.

## ماذا يفعل

- **أذكار الصباح** (31) و**أذكار المساء** (30) بالعدد والفضل كما في الورد اليومي المشهور.
- بقية أبواب حصن المسلم: النوم، الصلاة، الطعام، السفر، الحج، وغيرها. أكثر من 130 بابًا تعمل بدون اتصال.
- الضغط على الشريط الأخضر ينقص العدّ مرة، والإبقاء عليه يعدّ بسرعة. عند الصفر تظهر علامة التمام. أذكار النوم والأحلام مرتبة كما في صفحة إسلام بوك.
- **لوحة اليوم** تحسب التكرارات والأبواب المكتملة وسلسلة الأيام التي أُتمّ فيها الصباح والمساء.
- **تذكير** إذا جاء وقت الصباح أو المساء ولم يُقرأ الورد. الوقت الافتراضي 06:00 و16:30 ويمكن تغييره من الإعدادات.
- على الهاتف وسطح المكتب يُجدول التنبيه حتى لو كان التطبيق مغلقًا. على الويب يظهر التذكير داخل التطبيق، ويمكن إرسال تنبيه المتصفح من زر «تجربة التنبيه».
- عند أول فتح تظهر شاشات تعريف قصيرة، ثم لا تعود. حجم خط الذكر يُكبَّر من الإعدادات، والنص القرآني بخط مصحف المدينة مع رقم الآية داخل الدائرة.

## التشغيل

ثبّت [Flutter](https://docs.flutter.dev/get-started/install) ثم:

```bash
flutter pub get
flutter run -d chrome
```

نسخة الويب على منفذ محلي:

```bash
flutter run -d web-server --web-hostname 127.0.0.1 --web-port 43123
```

وبقية الأجهزة من المشروع نفسه:

```bash
flutter run -d android
flutter run -d ios
flutter run -d windows
flutter run -d macos
flutter run -d linux
```

ملف اختبار أندرويد (يعمل من أندرويد 7):

```bash
flutter build apk --release
```

الناتج يكون في `build/app/outputs/flutter-apk/app-release.apk`. التوقيع الحالي مفتاح تجريبي، مناسب للتثبيت اليدوي وليس للنشر على متجر.

## المصدر

نصوص الصباح والمساء مرتبة على الورد اليومي المتداول. بقية الأبواب من كتاب حصن المسلم لسعيد بن علي بن وهف القحطاني، عبر ملف [Adhkar-json](https://github.com/rn0x/Adhkar-json) المتاح بلا قيد استخدام. خط الآيات هو خط مجمع الملك فهد لطباعة المصحف الشريف (KFGQPC HAFS Uthmanic Script)، ويُوزَّع كما هو دون تعديل. لإعادة بناء ملف البيانات:

```bash
python3 tool/build_azkar.py
```
